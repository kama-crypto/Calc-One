# Calc One

**A Calculus I solver that shows its work.** Enter a derivative, integral, limit or sum and Calc One returns the answer together with a step-by-step explanation that names the technique it chose and why.

Built with Python, Flask and SymPy by [@kama-crypto](https://github.com/kama-crypto).

<br clear="left">

> **Status:** ongoing project, not a finished product. It already works, and I plan to keep improving it throughout the year: more techniques, clearer explanations and a better interface (with potential animations/video explanations). Features listed below describe what works today.
> The source code is kept in a private repository while the project grows. This repository is the public showcase: description, screenshots and demo. Source code is available if requested to check or evaluate.

## Why I built it

Most calculators give an answer and stop. When you are learning calculus, the useful part is *which rule applies and why*. Calc One is built around that: the answer comes from a computer algebra system, and the explanation is generated by logic that reads the shape of the problem and picks the technique a student would use.

## What it can do

| Operation | Techniques it recognises and explains |
| --- | --- |
| **Derivatives** | Power rule, sum rule, constant multiple rule, product rule, quotient rule, chain rule (powers of an inner function, trig, exponential, log and inverse trig). Rules are applied recursively, so nested cases show every layer. |
| **Integrals** | Power rule, constant multiple rule, standard forms, u-substitution (detected from the pattern g(u(x))·u'(x)), integration by parts (detected for polynomial × transcendental). Definite integrals also show the Fundamental Theorem of Calculus step. |
| **Limits** | Direct substitution first. If that is indeterminate: factor and cancel, then L'Hôpital's rule for 0/0 and ∞/∞ forms. Limits at infinity include a comparison of growth rates. |
| **Sums** | Closed-form formulas for Σi, Σi² and Σi³, geometric series, and a convergence check for infinite series. |

## Example problems

These are real outputs from the app.

| Type | Input | Result | Technique shown |
| --- | --- | --- | --- |
| Derivative | x³·sin(x) | x²(x·cos x + 3·sin x) | Product rule |
| Derivative | ln(x) / x | (1 − ln x) / x² | Quotient rule |
| Definite integral | 2x·cos(x²) from 0 to 1 | sin(1) | u-substitution, then Fundamental Theorem of Calculus |
| Indefinite integral | x·eˣ | (x − 1)eˣ + C | Integration by parts |
| Limit | sin(x) / x as x → 0 | 1 | Direct substitution gives 0/0, so L'Hôpital's rule |
| Sum | Σ i² for i = 1 to 10 | 385 | Closed-form sum-of-squares formula |

### Sample worked solution: d/dx [ x³·sin(x) ]

1. The expression is a product of two non-constant functions, so the power rule alone does not apply. Use the product rule: (fg)′ = f′g + fg′.
2. Take f = x³ and g = sin x. Then f′ = 3x² and g′ = cos x.
3. Substitute and simplify: **x²(x·cos x + 3·sin x)**.

## How it works

- **Solver engine:** looks at the structure of the expression, decides which technique applies and writes the explanation as it goes. The final answer is computed with SymPy, so the result is mathematically correct even where the explanation is simple.
- **Web layer:** a small Flask server receives the problem as JSON and returns the answer plus the list of steps.
- **Interface:** a single-page UI with an operation picker and an input form. Results are typeset with MathJax.

**Tech stack:** Python · Flask · SymPy · HTML · CSS · JavaScript · MathJax

## Limitations

- Technique detection is functioned to match the structure of the expression. Unusual or hard problems still get a correct answer, but the explanation may be less detailed.
- Input is typed as text (for example `x^3 + 2*x - 5`), which can lead to syntax mistakes.
- Calculus I scope only: no multivariable calculus, differential equations or series expansions **yet**.
